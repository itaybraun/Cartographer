# Cartographer

A set of beginner-friendly guides to how software is built, run, and turned
into a business. No prior experience is needed.

[Start reading]({{ '/building-blocks/' | relative_url }}){: .btn .btn-primary }
[View on GitHub](https://github.com/itaybraun/Cartographer){: .btn }

## The three books

### 1. Building Blocks of Software
Servers, the cloud, databases, queues, serverless, and observability, explained
from scratch. Start here if you're new to technology.

### 2. Software Lifecycle
How software goes from an idea to a running product: planning, building,
testing, releasing, and maintaining it.

### 3. Building a Startup
How to turn an idea into a company: finding a problem, building a first
version, and growing from there.

## Where to go next

- **Building Blocks of Software**: the best place to begin
- **Software Lifecycle**: how software gets made and shipped
- **Building a Startup**: from idea to first customers
