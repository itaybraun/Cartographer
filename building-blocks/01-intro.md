# Introduction
{: .no_toc }

Welcome! This guide explains how modern software is built, with no
technical background needed.

## Why this guide?

Every app you use, from a banking app to a video stream, is made of
smaller pieces that work together. Once you know what these pieces are, the
technology world becomes much easier to understand.

Think of building a house. You don't need to be an engineer to know a
house has walls, a roof, plumbing, and electricity. Software is the same:
it has **servers**, **databases**, **queues**, and more.

## What you'll learn

By the end of this guide you will be able to:

- Explain what a server and "the cloud" are
- Understand where and how applications store data
- Tell the difference between a service, SaaS, and serverless
- Describe how systems talk to each other using queues
- Understand why observability matters

## How to use this guide

Each chapter covers one building block, starting with a real-world
analogy before any technical terms. Read the chapters in order, or jump to
the one you need.

{: .note }
No prior experience is needed. If a term is new, don't worry. It will be
explained when it first appears.
